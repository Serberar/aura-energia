## Roles del Sistema

El sistema tiene 4 roles de usuario, cada uno con diferentes niveles de acceso:

### Comercial
- Buscar clientes
- Crear ventas
- Acceso a aplicaciones externas

### Verificador
- Todo lo del comercial
- Ver listado de ventas
- Verificar y editar ventas
- Cambiar estado de ventas
- Gestionar grabaciones

### Coordinador
- Todo lo del verificador
- Editar registros de clientes
- Eliminar grabaciones
- Supervisión del equipo

### Administrador
- Acceso completo al sistema
- Gestión de productos
- Gestión de estados de venta
- Dashboard de estadísticas
- Creación de usuarios

---

## Acceso al Sistema

Para acceder al sistema necesitas:

1. **URL de acceso**: Proporcionada por tu administrador
2. **Usuario**: Tu nombre de usuario asignado
3. **Contraseña**: Tu contraseña personal

Si no tienes credenciales o has olvidado tu contraseña, contacta con tu administrador.
